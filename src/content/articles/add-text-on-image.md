## Why You Need to Add Text

When you make graphics or add captions to pictures you need a tool to put text on top of the image.

## How the Add Text Tool Works

This tool puts text on a picture using coordinates and custom font settings so it works really fast and you can see the text right away without having to send anything over the internet.

## When to Use the Add Text Tool

You should use the **Add Text** tool when you want to write your text on a picture like when you are adding captions making funny pictures or designing posts for social media.

## Step-by-Step Usage

1. **Upload your photo**: Upload the photo you want to use.

2. **Add text to your photo**: Click to add a text box type what you want to say and pick the font and color you like.

3. **Download your photo with text**: Download the picture with the text on it.

## Advantages of the Add Text Tool

- **You can customize it**: You can use fonts, colors and put the text wherever you want.

- **It looks clean**: The text looks nice and clean, on the picture.

- **It works in your browser**: The **Add Text** tool works in your browser so you do not need to send anything to a server.

## How to Use the Add Text Tool Safely

Before you download or share your picture make sure you check it to see if everything is okay. If you are working with files you should understand how the tool works and if it uses a server or just your browser.

## Asked Questions

### What kinds of fonts can I use with the Add Text tool?

The **Add Text** tool supports the fonts that're already on your computer and custom Google Fonts that are loaded on the page.
